# Exam Topper

*Source: Practice-Test 1, 12*

Given the marks of `N` students, return the **maximum** marks scored by any student.

`static int maxMarks(int[] marks, int N)` in `class Result`

Constraints: `1 <= N <= 10^5`, `-1000 <= marks[i] <= 1000`

| Input | Output |
|---|---|
| `20 30 93 71 18 82 66` | `93` |
| `33 45 67 33 67` | `67` |

Edit `Solution.java`, then run:  `python3 judge.py exam-topper`
