# Sum of Elements in the Kth Row of a Matrix

*Source: Practice-Test 8*

Read `R C`, the `R x C` matrix, then `K` (0-based). Print the sum of row `K`.

```
3 5
1 3 5 7 9
2 4 6 8 10
2 6 9 3 4
2
```
Output `24`

Constraints: `1 <= R,C <= 100`, `0 <= K < R`, `-1000 <= matrix[i][j] <= 1000`

Edit `Solution.java`, then run:  `python3 judge.py sum-of-kth-row`
