# The Airline Ticket - Concatenate two strings

*Source: Practice-Test 10*

Concatenate two strings **without** `String.concat` / `+`: copy `str1` followed by `str2` into the char array `result` (it is at least `len1 + len2` long).

`static void strcat(char[] result, char[] str1, char[] str2)` in `class Main`

`Code` + `Quotient` -> `CodeQuotient`, `John` + `Doe` -> `JohnDoe`

Edit `Solution.java`, then run:  `python3 judge.py airline-ticket-concat`
