# Matrix Multiplication

*Source: Practice-Test 7*

Multiply `A (R1 x C1)` by `B (C1 x C2)` and return the `R1 x C2` result.

`public static int[][] multiply(int[][] A, int[][] B, int R1, int C1, int C2)` in `class Main`

`[[1,2,3],[4,5,6]] x [[2,3],[1,2],[2,1]]` -> `[[10,10],[25,28]]`

Constraints: `-1000 <= elements <= 1000`

Edit `Solution.java`, then run:  `python3 judge.py matrix-multiplication`
