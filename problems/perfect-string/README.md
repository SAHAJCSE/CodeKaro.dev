# Perfect String

*Source: Practice-Test 8*

A string made only of `a`, `b`, `x`, `y` is **perfect** if the number of `a`+`b` characters is **odd** and the number of `x`+`y` characters is **even**.

`public static boolean isPerfect(String str)` in `class Result`

`xaxbyyb` (3 / 4) -> YES, `aabbxxyy` (4 / 4) -> NO, `abaabxy` (5 / 2) -> YES, `yyxaby` (2 / 4) -> NO

Edit `Solution.java`, then run:  `python3 judge.py perfect-string`
