# Employee

*Source: Practice-Test 7*

Track six months of salaries for an employee.

| Method | Behaviour |
|---|---|
| `void getValues(int id, String name, int[] salary)` | store the data |
| `void printValues()` | print id, name (may contain spaces), the six salaries space-separated - 3 lines |
| `int calTotalSalary()` | sum of the six salaries |
| `int maxSalary()` | month number (1-6) of the highest salary |

Sample: `3234 / Nitin Kumar / 12313 12001 10333 14923 15783 10010` -> total `75363`, max in month `5`.

Edit `Solution.java`, then run:  `python3 judge.py employee`
