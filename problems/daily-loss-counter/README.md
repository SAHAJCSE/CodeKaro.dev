# The Daily Loss Counter

*Source: Practice-Test 5, 13*

Count the days with a **loss**, i.e. net performance strictly less than 0.

`public static int count(int[] a, int T)` in `class Solution`

`1 2 3 -5` -> `1`

Constraints: `1 <= T <= 1000`, `-10^6 <= a[i] <= 10^6`

Edit `Solution.java`, then run:  `python3 judge.py daily-loss-counter`
