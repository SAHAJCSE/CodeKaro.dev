# Class Student

*Source: Practice-Test 8*

Design `class Student`:

| Member | Behaviour |
|---|---|
| `Student(int studentId, String name, int[] marks)` | initialise (5 marks) |
| `void printValues()` | line 1 id, line 2 name, line 3 the five marks space-separated |
| `int calTotalMarks()` | sum of the five marks |
| `int secondMaxMarks()` | second highest mark |

Sample: `14 / Deepak Singh / 57 85 45 86 95` -> total `368`, second highest `86`.

Edit `Solution.java`, then run:  `python3 judge.py class-student`
