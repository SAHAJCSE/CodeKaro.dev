# Sum of elements of matrix

*Source: Practice-Test 6*

Read `rows`, `cols`, the matrix, a row index `r` and a column index `c` (0-based). Print **sum(row r) + sum(column c)**
(the element at `[r][c]` is counted twice).

Input
```
2
3
1 2 3
4 5 6
0
0
```
Output `11`  (row0 = 6, col0 = 5)

Edit `Solution.java`, then run:  `python3 judge.py matrix-row-and-column-sum`
