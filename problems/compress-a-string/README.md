# Compress a string

*Source: Practice-Test 5*

Compress a string: every run of the same character longer than 1 is replaced by the character followed by the run length. Single characters stay unchanged.

`public static String compressString(String str)` in `class Main`

`aabbccdef` -> `a2b2c2def`, `abddddddd` -> `abd7`

Edit `Solution.java`, then run:  `python3 judge.py compress-a-string`
