# Put even and odd elements in 2 separate arrays

*Source: Practice-Test 14*

Split the array into an array of even elements and an array of odd elements (keep the original order), then **print** the even elements on the first line and the odd elements on the second line, space-separated. Do not read input.

`static void separate(int a[], int n)` in `class Main`

`1 3 5 8` -> `8` / `1 3 5`

Constraints: `1 <= n <= 100`, `-10^9 <= a[i] <= 10^9` (negative odd numbers exist!)

Edit `Solution.java`, then run:  `python3 judge.py separate-even-odd`
