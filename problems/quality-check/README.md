# Quality Check (even / odd count)

*Source: Practice-Test 4, 11*

Given `T` integers, print the count of **even** and **odd** elements on one line separated by a space (even first).

`static void count(int[] a, int T)` in `class Solution`

`1 3 5 8` -> `1 3`

Constraints: `1 <= T <= 100`, `1 <= a[i] <= 10^5`

Edit `Solution.java`, then run:  `python3 judge.py quality-check`
