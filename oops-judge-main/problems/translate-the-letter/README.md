# Translate The Letter

*Source: Practice-Test 2*

Reverse the **order of the words** in a sentence (words are separated by exactly one space, no leading/trailing spaces).

`static String translate(String letter)` in `class Result`

`Code Loves Quotient Code` -> `Code Quotient Loves Code`
`Coders Hello` -> `Hello Coders`

Constraints: sentence length <= 100000

Edit `Solution.java`, then run:  `python3 judge.py translate-the-letter`
