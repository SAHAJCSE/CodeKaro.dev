# Sum of Lower Triangle of a Square Matrix

*Source: Practice-Test 10*

Read `N` and an `N x N` matrix. Print the sum of the **lower triangle including the main diagonal** (elements with `col <= row`).

```
3
1 2 3
4 5 6
7 8 9
```
Output `34` (1 + 4 + 5 + 7 + 8 + 9)

Constraints: `1 <= N <= 5`, `-100 <= matrix[i][j] <= 100`

Edit `Solution.java`, then run:  `python3 judge.py sum-lower-triangle`
