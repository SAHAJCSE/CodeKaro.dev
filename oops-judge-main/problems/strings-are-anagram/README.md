# Strings are anagram or not

*Source: Practice-Test 9*

Two strings are **anagrams** if they contain the same characters (case matters) with the same frequencies. Return `1` if anagram, else `0`.

`static int isAnagram(String str1, String str2)` in `class Main`

`act`/`cat` -> 1, `CodeQuotient`/`QuotientCode` -> 1, `Hello`/`Hillo` -> 0

Edit `Solution.java`, then run:  `python3 judge.py strings-are-anagram`
